Static E-commerce Homepage

 
A fast, static e-commerce-style homepage built with React (via Vite) and TailwindCSS. This demo project includes a hero section, product and category listings, a simple cart (using localStorage), and multiple routed pages. Perfect for showcasing products or building a basic e-commerce frontend prototype.

 Features
 
- Responsive homepage with Hero section and call to action (CTA)
- Products grid with filtering 
- Simple cart with localStorage persistence
- Multiple pages: Home, Products, Cart, About, Contact
- Fully client-side routing using React Router DOM
- TailwindCSS utility-first styling for rapid UI development
- Placeholder product images using 

Pages

- Home – Landing page featuring Hero and selected products.
- Products – Grid layout of all products with filters and category selection.
- Cart – View of selected products with localStorage persistence.
- About– Information about the store.
- Contact– Contact form or contact information.

Tech Stack

- Frontend: React 19 + Vite 7
- Styling: TailwindCSS 4
- Routing:React Router DOM 7
- Linting: ESLint 9
- Other:LocalStorage-based cart, static assets
  Prerequisites
- Node.js 18+  
- npm (or Yarn/pnpm)
